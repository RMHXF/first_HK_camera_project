# 5月17日开发日志
## ubuntu中视觉开发环境的搭建
### 1  更新ubuntu相关依赖文件
```
sudo apt update
sudo apt upgrade
```
更新完后还有几个开发包得安装
```
sudo apt install g++
```
这是c++的编译环境
```
sudo apt install git
```
这是代码管理应用的安装
```
sudo apt install vim
```
ubuntu环境下的文本编辑器

还要安装vscode，我建议不要用snap命令安装，需要在官网上下载vsdcode的deb包后再通过dkpg命令下载。示例代码如下：
```
sudo dpkg -i vscode.deb
sudo apt-get -f install
```

然后就是安装scode的插件。这里需安装如下插件：
C/C++；Chinese(Simplified);cmake tools;color highlight;

## MVS配置
### 1 去官网下载MVS
下载链接在这：https://www.hikrobotics.com/cn/machinevision/service/download/?module=0

解压后按照里面的readme说明进行安装

### MVS闪退，脚本无法运行问题
```
robomaster@RMSentry:/opt/MVS/bin$ ./MVS.sh
not root user
Must construct a QGuiApplication before accessing a platform theme hint.
"execCommand : xdpyinfo | grep dimensions"
Warning: Ignoring XDG_SESSION_TYPE=wayland on Gnome. Use QT_QPA_PLATFORM=wayland to run on Wayland anyway.
qt.qpa.plugin: Could not load the Qt platform plugin "xcb" in "" even though it was found.
This application failed to start because no Qt platform plugin could be initialized. Reinstalling the application may fix this problem.

Available platform plugins are: eglfs, linuxfb, offscreen, wayland-egl, wayland, wayland-xcomposite-egl, wayland-xcomposite-glx, xcb.

已中止 (核心已转储)
```
出现以上报错，只需要执行以下命令：
```
sudo apt install libxcb-*
```
安装好所有MVS中需要的libxcb相关的库即可

## 找到MVS的开发文件
一般在/opt/MVS/这个路径下，着重注意里面的include文件夹，里面有MVS的接口文件,以及lib文件夹，里面有MVS的动态链接库文件。后续cmake路径的配置中，需要将这两个路径加入到cmake的搜索路径中。
